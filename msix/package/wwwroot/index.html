1. Importar um mês

Cole a agenda copiada

Copie a tela do relatório da prefeitura — de um mês só ou de um período maior, como o ano inteiro — cole aqui e incorpore os agendamentos ao histórico.

Como funciona. Cada mês é identificado pela data de cada agendamento, então um único texto colado pode conter vários meses de uma vez. Se algum desses meses já existir, a versão armazenada será substituída para evitar duplicidades.

Armazenamento

Instale este app no seu celular ou computador para abrir como um programa, mesmo sem internet.

Os registros ficam somente neste navegador, por meio do armazenamento local. Nada é enviado para a internet por esta página.
