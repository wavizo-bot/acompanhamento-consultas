Manual do Projeto: Acompanhamento de Consultas
==================================================

Visão Geral
-----------

Funcionamento do App
--------------------
1. **Importação**: Usuário copia/cola relatório da prefeitura (texto bruto) no textarea.
2. **Parse**: JS extrai agendamentos por regex (data, CNS/CPF, paciente, telefone, situação).
3. **Armazenamento**: Salva em `localStorage` chave `acompanhamento-consultas-v1` como JSON `{reports: [{monthKey, entries[], importedAt}]}`.
4. **Filtros**: Por situação contida, última situação, meses selecionados.
5. **Ordenação**: Alfabética, recentes, antigos, habituais, inabituais.
6. **Saída**: Tabela copiável (TSV para planilha) e imprimível (CSS `@media print`).
7. **PWA**: Instalável, offline via Service Worker, `display: standalone`.

Tecnologias
-----------
- **Frontend**: HTML5, CSS3 (custom properties, grid, print styles), Vanilla JS (ES6+)
- **PWA**: Web App Manifest, Service Worker (cache-first app shell)
- **MSIX**: WebView2 (Edge Chromium embedded), `runFullTrust` capability
- **Deploy PWA**: Netlify / Vercel (static hosting com HTTPS)
